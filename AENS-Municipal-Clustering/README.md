# Municipal Clustering with PCA

Multivariate analysis of Portuguese municipalities using demographic, economic, education and social indicators.

## Methods

- Data integration and missing-value treatment
- Principal Component Analysis with Varimax rotation
- Hierarchical clustering with Ward linkage
- K-Means and Gaussian Mixture Models
- Silhouette analysis and cluster profiling

`analysis.R` contains the complete workflow. The `data/` directory contains the small public indicator extracts used by the analysis. The final report and presentation are included for context.
