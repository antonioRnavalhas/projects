# Macroeconomic Time-Series Forecasting

Forecasting project that combines European macroeconomic series, stationarity diagnostics, Granger analysis and out-of-sample model comparison.

## Contents

- `analysis.ipynb` — complete modelling workflow
- `utils/` — reusable data, diagnostics, forecasting, metrics and plotting modules
- `seeds/` — compact source series used by the notebook
- `figures/` — selected final visualizations
- `report.tex` — final report source

Generated caches, assignment materials and duplicate report drafts were excluded.
