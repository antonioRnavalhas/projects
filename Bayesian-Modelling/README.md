# Bayesian Parallel Mediation

Bayesian parallel-mediation analysis implemented in R and Stan, with weak, moderate and informative prior scenarios.

## Methods

- Data preparation and standardized predictors
- Custom Stan model for parallel mediation
- MCMC diagnostics and trace plots
- Posterior summaries and scenario comparison
- Direct, indirect and total-effect interpretation

The original research dataset and questionnaire were excluded from this public portfolio. The repository contains the analysis code, final figures, coefficient summary and report.
