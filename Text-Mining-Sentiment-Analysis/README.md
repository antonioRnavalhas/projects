# IMDb Sentiment Analysis

Text-mining project for classifying and interpreting sentiment in movie reviews.

## Contents

- `analysis.ipynb` — preprocessing, exploration, lexicon analysis and modelling
- `NRC-lexicon.csv` and `opinion_lexicon.csv` — compact sentiment resources
- `report.pdf` and `presentation.pptx` — final deliverables
- `requirements.txt` — Python dependencies

The large IMDb train/test files were excluded; obtain the public dataset separately before rerunning the complete notebook. Optional external-service credentials are loaded from environment variables and must never be committed.
