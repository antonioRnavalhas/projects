# António Navalhas — Data Science & Analytics Portfolio

Portfolio of data, analytics and machine learning projects covering statistical modelling, NLP, time series, big data and applied AI.

[LinkedIn](https://www.linkedin.com/in/antonio-navalhas-22831623b/) · [GitHub](https://github.com/antonioRnavalhas) · [Live demos](https://antoniornavalhas.github.io/projects/)

## Projects

- [AI Shopping Assistant](AI-Shopping-Assistant/) — multilingual FastAPI product discovery application with explainable ranking and tests. [Live static demo](https://antoniornavalhas.github.io/projects/ai-shopping-assistant/)
- [E-commerce Conversion Propensity](Ecommerce-Conversion-Propensity/) — rare-event classification and purchase-intent ranking. [Live presentation](https://antoniornavalhas.github.io/projects/ecommerce-conversion/)
- [Municipal Clustering](AENS-Municipal-Clustering/) — PCA and clustering of Portuguese municipal indicators.
- [Airbnb Price Modelling](Predictive-Modelling-Airbnb/) — regression, trees, bagging, random forest and boosting.
- [Time-Series Forecasting](Time-Series-Forecasting/) — macroeconomic forecasting and model comparison.
- [Bayesian Modelling](Bayesian-Modelling/) — Bayesian parallel mediation estimated with Stan.
- [Sentiment Analysis](Text-Mining-Sentiment-Analysis/) — lexicon and machine-learning analysis of IMDb reviews.
- [Massive Data Processing](Massive-Data-Processing/) — PySpark data preparation, PCA and K-Means applied to music data.
- [ATP Tennis Database Engineering](ATP-Tennis-Database-Engineering/) — MongoDB projection, relational modelling, data cleaning and analytical SQL.

Each folder contains its own documentation, implementation and selected final deliverables.
