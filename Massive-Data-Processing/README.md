# Massive Data Processing for Music Analytics

Two-stage data-engineering and analytics project using Billboard chart history and audio features.

## Scope

- Distributed data preparation with PySpark
- Data-quality diagnostics and type correction
- Song-level aggregation and dataset joins
- Missing-value treatment and normalization
- PCA, K-Means selection and cluster profiling
- Outlier inspection and reporting

The repository includes the final notebooks and reports for both phases. Large third-party datasets and course guides were excluded from the public portfolio.
