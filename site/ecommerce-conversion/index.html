Project case study

Intra-session purchase propensity model

A prototype to rank website sessions by likelihood to purchase and activate high-intent audiences in marketing and personalization workflows.

The model is valuable if it concentrates buyers in the top-scored sessions, not if it maximizes plain accuracy.

Data and assumptions

Session-level anonymized e-commerce session data

Dataset

  • Anonymized e-commerce session data
  • Period: July to August 2017
  • Target: transaction within the session
  • Features: traffic source, device, geo, page path and timing

Cleaning rule

  • Modelling unit: one row per session
  • Duplicated sessId values were deduplicated
  • First observed row kept for features
  • Session target set to max(transaction)
Data foundation 03
Modelling approach

Two scoring moments, two use cases

Entry model

Can be scored near the beginning of the session.

  • Traffic medium and source
  • Device, browser and geography
  • Landing page, time and visitor history

Intra-session model

Can be scored after further behavior is observed.

  • Second and third page visited
  • Page timing signals
  • More accurate, but later intervention point

Limitations and roadmap

Prototype first, production with validation

Limitations

  • One month of public demo data
  • Scores optimized for ranking, not exact probability calibration
  • Intra-session signals are only available after browsing behavior occurs

Next steps

  • Add richer customer, product, margin and media cost data
  • Calibrate scores on a validation period
  • Run controlled experiments and monitor drift
  • Consider uplift modelling for intervention decisions
Recommended path: use the model to create testable high-propensity audiences, then prove incremental business impact before scaling.
